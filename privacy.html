Privacy Policy

Last updated: October 19, 2026

Purpose

Kanka NAS Backups is a private, self-hosted backup utility used to store encrypted backups in the owner's Google Drive account.

Google Drive Access

The application requests Google Drive access to create, read, and manage backup files.

Data Storage and Security

Backup files are encrypted locally using rclone crypt before being uploaded to Google Drive.

Google OAuth credentials and encryption passwords are stored privately and are not published on this website.

Data Sharing

The application is intended for personal use. It does not sell user data or share Google Drive data with advertisers.

Data Deletion

The owner can delete backup files from Google Drive and revoke application access through Google Account security settings.

Contact

For questions about this application, contact the developer using the support email listed on the Google OAuth consent screen.
